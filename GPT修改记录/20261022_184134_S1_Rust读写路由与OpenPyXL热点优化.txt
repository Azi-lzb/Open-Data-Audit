时间：2026-10-22 18:41（Asia/Shanghai）
范围：S1-F01、S1-F02；S4 仍为预览 UI，不在本轮实现范围。S5 近期已优化，本轮没有修改 S5 业务代码。

## 实现与边界

- S1-F01 新建审核结果工作簿增加独立 AUTO / Rust xlsxwriter / OpenPyXL 写入路由。AUTO 有可用 sidecar 时优先 Rust，失败后安全回退；用户显式选择 Rust 时不可用或失败会明确报错。
- S1-F01 保留原工作表/单元格跳转、外部文件链接、链接显示文字、表头、冻结窗格、筛选及列宽。Rust 生成后只恢复 XLSX 关系中的原始外部路径，避免 URL 编码改变本地文件目标。
- S1-F02 将纯 Python 汇总管线的源值读取单独路由为 AUTO / Calamine / OpenPyXL；AUTO 优先 Calamine，仅自动模式回退。新建汇总结果工作簿单独路由为 AUTO / Rust xlsxwriter / OpenPyXL。
- S1-F02 的模板及命名区域读取、结构预检、公式拷贝和 Office 公式缓存刷新不变；未迁移公式计算。S1-F01 的审核副本公式复制与 Excel/WPS 重算也不变。
- 设置中心为 S1-F01 写入、S1-F02 源读取和 S1-F02 结果写入分别保存选择；各功能 AUTO 默认可用路线。
- Windows AMD64 与 Linux AMD64 writer sidecar 已构建，Flask、PyWebView 及 Linux 发布入口按包含 S1 的产品 profile 可选收集；未生成产品安装包/便携包。

## 性能与对拍

Windows 当前环境，重复运行取中位数，计时含 Rust sidecar 进程调用；不以 XLSX ZIP 字节相同作为正确条件：

- S1-F02 源值读取，3 个工作簿、9,000 行、12 列：Calamine 0.1661 秒，OpenPyXL 1.1905 秒，约 7.17 倍；读取结果及绝对坐标一致。
- S1-F02 新建汇总表：1,000 行 Rust/OpenPyXL 0.0444/0.1917 秒（4.32 倍）；5,000 行 0.1439/0.8677 秒（6.03 倍）；20,000 行 0.5256/3.5827 秒（6.82 倍）。对拍值、行列、工作表、冻结、筛选及列宽。
- S1-F01 审核结果表含逐行文件跳转：1,000 条问题 Rust/OpenPyXL 0.419/1.532 秒（3.66 倍）；3,000 条 1.228/7.980 秒（6.50 倍）。对拍单元格值、外部文件目标、工作表/单元格位置、显示文字、表头、冻结、筛选、列宽与链接样式。
