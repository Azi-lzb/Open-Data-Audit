【实现】
公共 native 安装器独立于审核任务、业务核心和六册配置。共享 WebApi 提供 get_libreoffice_install、choose_libreoffice_source、start_libreoffice_install，路径选择器新增复合扩展名过滤。
帮助页 Linux 专属第三子页提供两种方式，默认辅助安装；终端说明 cd -- "/实际路径/DEBS" 与 sudo dpkg -i *.deb，指出 -i 后的空格及密码输入方式。手动命令只是文案，不交给后端执行。
后台检查并暂存 DEB 文件。归档限制成员数、层级、总大小、磁盘空间，拒绝路径穿越、重复项、链接和特殊文件；文件夹限制扫描数量。读取 dpkg-deb 的真实带字段名信息，核对唯一主包、核心/Calc 组件、版本和架构，安装前再检查暂存 SHA256。
实际官方包中 41 个主程序包 7.6.7.2-2/amd64、菜单包 7.6.7-2/all。仅针对同版本菜单包三段版本兼容，其余核心包须与主包精确一致；ure/uno-libs-private 也不能混版。
安装 argv 固定为 pkexec --disable-internal-agent /usr/bin/dpkg --install 加绝对暂存文件；已是 root 时直接调用固定 dpkg。无 shell 用户命令、无密码字段/日志、无自动联网依赖修复、无卸载/强制覆盖参数。
恢复冻结程序调用系统工具时的系统库环境；等待真实安装进程结束，不因任意超时中断包管理器。清理完成后发布终态，避免旧安装清空新准备任务。安装与审核启动检查共用锁，阻止并发启动；未改变业务算法。
安装成功必须确认 /opt/libreoffice<主.中>/program/soffice 的本次目标版本可启动，不以其他已安装版本替代证明；成功后刷新环境摘要。
Flask 安装接口仅接受本机回环/主机名的 JSON 请求，Origin 存在时须同源；错误 Origin、跨站、非 JSON 和远程请求被拒绝。
