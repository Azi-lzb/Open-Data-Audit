【修改目的】
增加一个可由用户双击运行的 Windows BAT，用于自行执行 core 全量 pytest 并直接查看测试摘要与退出状态。

【修改文件】
新增：运行全量测试.bat

【脚本行为】
从 BAT 所在目录切换到项目根目录；按 .venv、PATH 中的 python、py -3 顺序寻找能导入 pytest 的 Python；打印解释器和测试命令；运行 python -m pytest -q -rs core/tests；打印 PASS/FAIL 与退出码。默认暂停以便双击后查看，传入 --no-pause 时不暂停。不会自动安装依赖；缺少 pytest 时提示安装命令。运行时临时设置 UTF-8 代码页，结束时恢复原代码页。
