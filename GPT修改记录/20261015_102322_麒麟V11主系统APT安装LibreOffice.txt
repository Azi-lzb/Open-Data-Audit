# 麒麟 V11 主系统 APT 安装 LibreOffice

日期：2026-10-15 10:23（Asia/Shanghai）

## 修改概述

- 根据用户提供的麒麟 V11 实机结果，修正此前“V11 必须通过 KARE 安装和运行 LibreOffice”的判断：用户已在 Maintain Mode 下使用 `sudo apt install ./*.deb` 成功安装，并报告 S1-F1 直接发现主系统 LibreOffice、实测成功。
- 内置 Linux DEB 安装器改为优先通过系统 `apt-get` 一次安装整组已校验的包，让 APT 处理依赖；没有 APT 时回退 `dpkg`。安装后校验主系统 Calc 版本，不再自动写入 KARE 配置。
- V11 检查完成提示与失败提示加入 Maintain Mode 指引；程序不会自行切换系统模式或重启。
- S1-F1 的直接 LibreOffice 调用逻辑不因本次 V11 路径调整而改变；保留既有可选 KARE 计算适配，但 V11 默认安装路径不依赖它。
- 更新 Linux 安装说明、README、V11 调查文档、产品发布记录和版本清单说明。
