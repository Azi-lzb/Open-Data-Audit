# S2-F01：机构行标签列缺失时按 0 继续外部核对

时间：2026-10-20 16:11:15

【需求】
执行 S2-F01 时，如果“集中系统数据”未识别到机构行标签列，不要报错退出；继续执行，外部系统数按 0 填入结果。

【实现】
- 导入器遇到机构行标签列缺失时写入专用、显式标记的零值兜底，不影响正常导入路径。
- 外部核对引擎仅在识别到该专用标记时采用 0，并在审核说明标出“机构行标签列未识别，外部数按0参与比较”。
- 普通机构映射缺失或指标值缺失仍保留原先的“未找到大集中系统数据”处理，不一概改成 0。
- 增加导入层与引擎层测试，覆盖兜底值、差异计算及普通缺数语义。
