shell-flask 目录文件说明
========================================

本目录是 V3「基础数据审核工具」的 Flask 外壳，Windows 和 Linux/UOS 共用。
业务核心在 ../core/，这里只放启动和打包入口。

命名规则：平台前缀 + 序号，序号即常用顺序（1 启动 → 2 打包 → 3 冒烟 → 4 源码包）。
完整开发文档见 README.md，本文件是速查卡。

【Linux/UOS 侧】
Linux-1-启动审核工具.sh        启动审核服务（前台运行，Ctrl+C 停止；--background 后台启动）
Linux-1-启动审核工具.desktop   同上的双击入口，后台启动并自动打开浏览器，不弹终端
Linux-2-打包DEB与TARGZ.sh      统一构建引擎：一次构建 DEB + tar.gz 两种产物。
                               DEB = 安装包（装到 /opt、加开始菜单）；tar.gz = 免安装便携包。
                               只想出一种时加参数：--skip-deb 或 --skip-tgz
Linux-3-测试发行包启动.sh       打包后冒烟：校验 SHA-256 → 解包 → 启动 → 检查网页 → 关服务，
                               自动测 dist/ 下最新的 .deb 和 .tar.gz，全部通过才退出 0；
                               也可指定产物路径测试。分发前建议必跑
Linux-4-打包UOS源码验收包.sh    生成可外发的源码验收包（ZIP/TAR，源码+脚本+空表头配置，
                               不含冻结程序和业务数据；目标机需 python3 + LibreOffice Calc）

【Windows 侧】（在 Windows 机器上运行）
Windows-1-启动审核工具.bat     源码模式启动；加 --packed 参数用打包版 EXE 启动
Windows-2-打包Win10Win11.bat   构建 Win10/11 64 位 EXE（Python 3.11/3.12）
Windows-3-打包Win7.bat         构建 Win7 兼容 32 位 EXE（Python 3.7/3.8）
Windows-4-打包双版本.bat       一次打包两个 EXE 放进同一发布文件夹（对外分发推荐用它）

【内部文件 —— 请勿直接运行或删除】
app.py / run.py                Flask 应用与启动器（源码/冻结双模式识别）
build_exe.py                   Windows EXE 打包实现（被 Windows-2 调用）
build_win7.py                  Win7 版打包实现（被 Windows-3 调用）
build_windows_all.py           双版本打包实现（被 Windows-4 调用）
requirements.txt               Linux/源码运行依赖
requirements-win7.txt          Win7 构建依赖
requirements-win10win11-build.txt  Win10/11 构建依赖
README.md                      完整开发、打包、分发文档
dist/                          构建产物输出目录（不入版本库）
__pycache__/                   Python 缓存（不入版本库）

【典型流程】
本机开发调试      → 双击 Linux-1-启动审核工具.desktop
发布 Linux 发行包  → 运行 Linux-2 打包 → 运行 Linux-3 冒烟 → 通过后到 dist/ 取产物分发
源码验收交付      → 运行 Linux-4，产物在 dist/ 下
发布 Windows 版    → 在 Windows 上运行 Windows-4 → dist\ 发布目录
