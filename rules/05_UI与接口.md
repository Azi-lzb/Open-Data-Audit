# UI 与接口规则

## 前后端边界

- 前端调用统一桥接 API；业务实现位于 `core/`。
- `shell-flask/` 和 `shell-pywebview/` 不复制业务 API。
- 后端新增前端接口时，应同步接口说明/约定。
- 工作台命令栏只能调用工具内置动作，禁止把用户输入直接交给 shell。

## 设置页视觉与交互

设置中心采用 ToDesk 式行布局：
- 每项一行；
- 左侧名称 + 简短说明；
- 右侧控件；
- 是/否用 toggle；
- 多选一用下拉框；
- 相关项进入分组卡片；
- 说明写用户效果，不写底层实现细节。

路径/文件名：
- UI 默认显示文件名，不展示长绝对路径；
- 全路径放 tooltip；
- 可点击时通过已有 `open_path()` 之类受控 API 打开。

主界面：
- 左侧主导航；
- 每个业务系统独立页面；
- 执行按钮归属对应系统页面；
- 运行记录/日志可以全局共享。

## 用户错误与技术日志

用户提示必须回答：
1. 哪个文件/工作表/规则出了问题；
2. 用户能理解的原因；
3. 下一步怎么处理。

技术日志才记录：
- Python traceback；
- COM/UNO；
- rId/Relationship/part/Target；
- 内部错误码；
- 源 XML；
- 原始异常。

不要把底层异常原样当作主要用户提示。
