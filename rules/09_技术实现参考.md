## 汇总核查平台差异

| 环节 | Windows | UOS/Linux |
|---|---|---|
| 条件格式原生渲染（确有需要时） | Excel/WPS | OOXML 静态求值；需真实渲染时用 LibreOffice |
| 公式校验复制 | COM `Range.Copy` + 公式矩阵 | openpyxl 复制公式/样式 |
| 工作簿重算 | Excel/WPS COM | LibreOffice Calc/soffice |
| 计算结果提取 | openpyxl `data_only` | 重算保存后 openpyxl `data_only` |

公式复制/计算要求：

- Windows 使用独立 Office 实例；禁止逐个公式单元格 COM 读写。可使用 Range.Copy，并以 Snapshot 公式矩阵确保公式内容。
- UOS 先用 Python 写入公式，再由 LibreOffice 重算并保存；无 LibreOffice 时明确失败，不能使用旧缓存结果。
- 组合工作表仅处理结构和值，不调用公式计算引擎。
