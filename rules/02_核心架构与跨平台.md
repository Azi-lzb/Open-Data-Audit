# 核心架构与跨平台补充

总体架构与技术优先级见 `AGENTS.md`；Excel 文件处理细则见 `rules/03_Excel与OOXML边界.md`。本文件只约束平台适配边界：

- 平台差异集中在 `core/src/base_audit/engines/`、`core/src/base_audit/native/` 和两个 shell；业务流程不得散落 COM、UNO 或操作系统判断。
- Windows 真实工作簿计算使用 Excel/WPS；COM 延迟导入，使用独立隐藏实例，不关闭用户已有的 Office，并在 `finally` 中可靠关闭资源。
- UOS/Linux 静态文件处理使用 Python；需要真实重算时使用 LibreOffice Calc/UNO。缺少 LibreOffice 必须明确失败，不能拿旧缓存值冒充本轮结果。
- 平台专属代码修改后按影响范围做对应真机回归；未触及的平台边界不要求每次重复整套平台验收，规则见 `rules/07_测试与发布.md`。
