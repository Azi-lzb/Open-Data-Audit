# 开发入口与交付显示

## 开发启动与完整版

Windows Flask、Linux Flask 源码启动以及 pywebview 默认显示 S1—S4，点击导航直接进入。
已移除“功能暂未开放”拦截、标题“开放”五连击和旧 HZPBC 口令入口。
旧的 data/开发设置.json 不再读取或创建，已有文件无需删除，false 值不会影响导航。
S4 当前仍为预览页；显示菜单不代表地金业务功能已完成。

## S1/S2 分发包

由 shell-flask/distribution-profiles.json 的交付方案控制隐藏 S3/S4 导航及相关指引、问答和设置栏目。
S1/S2 分发包不附带 3.0—3.3 配置（包含默认配置及备份）；业务代码完整保留。
如需显示全部栏目，打开“关于”，在 2 秒内连续点击“关于审核工具”标题 5 次，
输入 HZPBC790 后点击“显示全部”。密码错误、取消或关闭弹框不会改变显示范围。
开放状态仅对本次后端运行有效，刷新浏览器保留，重新启动后恢复包内交付方案。
显示 S3/S4 后可以直接进入；执行 S3 业务前须另行导入其配置。
Linux 分发包内的启动脚本遵循包内交付方案，与源码开发启动不同。

## Bridge API

get_state() 保留 developerAccess 四项均 true、developerAccessMessage 为空的兼容字段，不再参与导航拦截。
unlock_distribution_ui(password) 验证交付显示口令，成功返回 ok 和 state，distributionUnlocked=true。
旧 unlock_developer_system 接口已移除。口令不写入日志或用户设置。

这些开发与交付管理调整只记录在开发日志中。
