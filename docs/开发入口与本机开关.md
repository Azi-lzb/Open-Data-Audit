# S1/S2/S3/S4 开发入口与本机开关

S1 逐笔统计系统、S2 报表采集系统默认开放；S3 大集中统计系统、S4 地金系统默认禁用。禁用系统普通点击显示“功能暂未开放”。Flask 与 pywebview 共用以下机制。

## 临时进入

先点击对应系统导航，弹出“功能暂未开放”提示，再快速连点标题中的“开放”两字 5 次（总计 2 秒以内），提示框切换为开发人员密码框。导航点击不计数，标题其他文字及正文也不计数；关闭提示或重新打开会清空次数。输入 `HZPBC`，点击“强制进入”；点击“退出”、遮罩或按 Escape 关闭弹框，Enter 可提交。

口令区分大小写。验证由共用后端执行，不在前端保存密码，也不写入运行日志。成功后仅开放当前系统，持续到后端进程退出。Flask 的同一个服务进程内，各浏览器窗口共享该开放状态。

S4 当前仅提供开发预览占位，没有地金业务实现。

## 持续开放

使用独立的 `core/data/开发设置.json`，不放进用户设置。源码运行的默认位置为项目下 `core/data/开发设置.json`；Windows 打包默认在程序目录下的 `core/data/开发设置.json`。若启动环境指定了 `BASE_AUDIT_PROJECT_ROOT`，则使用该目录下的 `data/开发设置.json`。

首次启动只在文件不存在时创建默认值，不覆盖已有文件：

```json
{
  "S1": true,
  "S2": true,
  "S3": false,
  "S4": false
}
```

分别将对应值设为 `true` 即可持续开放；`false` 禁用，四个系统均支持禁用后的连击口令入口。必须使用 JSON 布尔值，不能写字符串 `"true"`、数字或中文。缺失的键使用该系统默认值（兼容此前只有 S3/S4 的文件）；显式非法值按禁用处理。文件无法读取、格式错误或内容不是对象时，四项都按禁用处理，可修正文件或用口令进入。

每次状态刷新重读文件，通常约 800 毫秒生效。把当前系统改回 `false` 后，页面在刷新时切换至首个开放系统（按 S1→S4 顺序）；四项都关闭时进入设置中心。若该系统已通过口令临时开放，需重启后端才会撤销临时开放。

该文件是本机运行数据，受 `**/data/` 忽略规则保护，不提交到公开仓库。交付时维持 S1/S2 开放、S3/S4 禁用的默认值，不携带本机临时调整值。用户设置重置不会修改此文件。

## 共用 Bridge API

- `get_state()` 增加 `developerAccess: {S1: bool, S2: bool, S3: bool, S4: bool}`，值为本机开关与本次运行口令开放状态的合并结果；`developerAccessMessage: str` 为文件读取/格式提示，正常为空。
- `unlock_developer_system(system, password)` 接受 `S1`、`S2`、`S3` 或 `S4`；成功返回 `{ok: true, state: ...}`，失败返回 `{ok: false, message: ...}`。不返回或记录密码，不改写开发设置及用户设置。

此机制控制导航开放，不是业务接口授权或密码安全体系。S3 业务核心、真实配置、操作指引与 Q/A 不随本次开发入口调整。

本次变更只记入开发日志与 GPT 修改记录，不追加用户更新日志。
