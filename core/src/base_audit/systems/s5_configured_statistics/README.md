# S5 逐笔统计系统（配置版）

S5 只保留一个正式审核功能：**F1 汇总核查表校验**。执行时使用 S5 自己的审核规则和配置版引擎；不调用 S1-F01 的模板公式审核流程，也不包含 S1-F02 汇总校验结果说明。

## 隐藏配置维护工具

连续点击左侧 S5 导航 5 次（2 秒内）可显示或隐藏三个维护入口：

- **V_CUR / V_PRE 表达式参考**：按数字区域和完整表头路径生成可复制的本期取数表达式参考副本；需要上期表达式时将 `V_CUR` 改为 `V_PRE`。
- **V_EXT 外部表达式**：按机构参照和指标表头生成外部取数表达式参考副本。
- **校验公式 → 配置候选**：扫描模板校验区域公式，生成独立的候选审核工作簿与标注模板副本；候选规则默认禁用，人工确认后再复制到正式 S5 配置。

三个工具沿用 S5 主面板当前显示的“匹配模板”和“大集中系统数据”，不再单独维护重复的输入路径。V_CUR/V_PRE 与公式候选读取当前匹配模板；V_EXT 读取当前大集中系统数据。V_EXT 与 S5-F1 兼容普通报表布局，以及表头包含“数据日期”“行名称”的时序布局；时序数据按本期报告期精确匹配，不借用其他日期。维护工具设置仅保存输出目录、单位等选项，保存在 `data/s5/维护工具设置.json`；生成结果保存在各工具设置的输出目录，默认位于 `data/s5/维护输出/`。工具只读输入文件，不会直接改写模板、外部文件或正式 S5 配置。表达式参考工具目前支持 XLSX；公式候选工具支持 XLSX/XLSM。

## 配置工作簿

S5 配置只保留两张工作表：

- **审核规则**：S5 配置版引擎读取的规则表。
- **核查表校验结果**：按要求保留为空的历史表，目前不被 S5-F1 读取或更新。

公开配置模板只含表头，不带真实规则。本机正式配置中的 2,392 条候选审核规则全部为禁用状态，覆盖 19 项业务；候选内容仍需人工逐条筛选和确认。使用说明、条件格式触发、业务说明、任务说明等 4 张原 S1 格式工作表已从 S5 配置移除。

## 输入和识别

页面使用独立文件列表、配置、模板目录、外部数据和输出目录。配置检查和模板识别都由用户手动触发；也可手动选择模板文件。待处理文件以源工作表能否在模板中找到为主要匹配依据：模板中有、源文件中暂未出现的表不影响匹配；源文件新增的表会单独提示，不再显示笼统的“部分匹配”。匹配数量以源工作表为分母展示，并可按匹配状态、业务类型和日期筛选。业务由规则配置与源工作表识别，报告期按源文件名、源表报告期字段和所属文件夹依次识别；无法唯一识别时会提示处理。

外部核对需要选择大集中系统数据。没有启用规则、结构定位歧义、取数失败、公式错误或条件格式无法判定都会明确报告，不把空结果当作全部通过。输入支持 XLSX/XLSM。

## 上期和输出

页面暂不显示上期文件框，服务仍支持 previous_files、previous_period 和 V_PRE。未提供上期时，依赖 V_PRE 的规则会报告取数失败，不会静默跳过。

默认输出目录为源数据目录下的“执行结果”。F1 每次只在该目录生成一份汇总 XLSX，包含审核结果、条件格式与数据质量提示；不创建批次/机构子目录，不写审核副本或运行总账 JSON。结果单元格链接回原始源文件。运行记录显示配置加载、机构参照、文件识别、规则审核、模板公式扫描、条件格式扫描和结果导出的耗时。F1 不计算输入文件内容哈希，因此不会检测运行期间输入文件是否被并发修改。配置检查报告也保存到“执行结果”。配置检查和文件选择与 S1/S2/S3 页面隔离。

## 范围

S5 不保留 F2，也不把 S1 的汇总校验结果说明或模板公式审核入口复制到配置版。S1、S2、S3 原有实现与配置未因本次范围调整而修改。
